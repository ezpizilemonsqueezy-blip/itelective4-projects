# Creative Studio Dashboard

A polished React + TypeScript + Vite project designed to feel like a creative studio workspace. It presents a clean dashboard experience with project cards, progress tracking, and a modern studio-inspired layout.

## Features

- Modern card-based dashboard design
- Clear project status and progress display
- Responsive layout for desktop and mobile screens
- Built with React, TypeScript, and Vite

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local Vite URL in your browser.

## Project Theme

This project is styled to reflect a creative studio vibe with a fresh, minimal, and professional interface that highlights progress and priorities.
